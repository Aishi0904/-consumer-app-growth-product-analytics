# Data Quality Assessment

## Objective

Evaluate the reliability and consistency
of the source dataset before analysis.

## Validation Checks

1. Missing user identifiers.
2. Missing event names.
3. Missing timestamps.
4. Duplicate transaction identifiers.
5. Inconsistent date formats.
6. Invalid or missing revenue values.
7. Session identifier completeness.

## Data Treatment

All cleaning decisions will be documented.
Records will not be removed without a
clear analytical justification.

Data-quality findings will be updated
after SQL validation.
