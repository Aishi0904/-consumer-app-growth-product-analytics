# KPI Dictionary

This document defines the key performance
indicators used throughout the project.

| KPI | Definition |
|---|---|
| Total Users | Distinct user identifiers |
| Total Sessions | Distinct user-session combinations |
| Total Events | Total recorded events |
| Purchasing Users | Unique users with purchase events |
| Purchase Conversion Rate | Purchasing Users / Total Users |
| Total Revenue | Sum of purchase-event revenue |
| Average Order Value | Revenue / Transactions |
| Events per User | Total Events / Total Users |
| Repeat Purchase Rate | Repeat Purchasers / Purchasing Users |
| View-to-Cart Rate | Cart Users / Product Viewers |

All KPI calculations will be validated
against the underlying SQL results.
