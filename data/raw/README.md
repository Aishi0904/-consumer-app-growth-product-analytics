# Raw Dataset

This directory is reserved for original
source data and dataset documentation.

## Primary Data Source

Google Analytics 4 Public Ecommerce Dataset.

Source:
https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset

## Data Characteristics

- Event-level user interaction data
- User identifiers
- Event timestamps
- Product interactions
- Transaction information
- Acquisition source information
- Device and geographical attributes

The original dataset is accessed directly
through Google BigQuery.

Raw public data will not be duplicated
unnecessarily in this repository.
